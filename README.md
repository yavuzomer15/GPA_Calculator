GPA & CGPA Calculator – Qt C++ Application

This project is a GPA & CGPA calculator developed using Qt and C++, designed to dynamically calculate a student's academic performance.

Key Features:
Dynamic UI Elements: Users can input course grades and credits through dynamically created QLineEdit widgets based on the selected number of courses.
Real-Time GPA Calculation: The system computes GPA based on user inputs, updating the results dynamically.
CGPA Integration: A separate CGPA calculation window allows users to input their previous CGPA and total credits, enabling cumulative performance tracking.
User-Friendly Interface: The application features a clean and intuitive UI built with Qt Designer.
Event-Driven Design: The app leverages Qt’s signal-slot mechanism to update calculations instantly upon user input changes.
This project showcases Qt development, UI design, event-driven programming, and data handling in C++, making it a great addition to a portfolio for software engineering roles.
